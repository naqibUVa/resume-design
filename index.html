Start it

  1. macOS: double-click start.command in this folder.
  2. Windows: double-click start.bat.
  3. Linux, or from a terminal anywhere: 
    cd "Resume_design"
./start.sh

The script installs what is missing, starts a local server, and opens the real app in your browser. Leave its window open while you work — closing it stops the server.

Why opening the file directly cannot work

index.html loads /src/main.jsx. JSX is not JavaScript a browser understands, and import statements that name a package rather than a file path have no meaning over file://. A build step has to translate both first — that is what the start script runs. There is no version of double-clicking this file that works.

Already built it?

Then use the dist/ folder, not this file — and still serve it over HTTP rather than opening it, because browsers block module scripts on file://. ./start.sh --built does exactly that.
